# Bus Simulator Madagascar 3D

Prototype voalohany azo lalaovina amin'ny navigateur Android.

## Misy amin'ity version ity
- Three.js 3D scene
- Bus coach vita amin'ny géométrie 3D procedural (mbola tsy modely GLB externe)
- Lalana sy tontolo maitso, havoana, hazo ary trano
- Commandes tactiles: gauche/droite, accélérer, frein
- HUD vitesse sy distance
- Landscape/fullscreen request rehefa manindry Hanomboka

## Fanombohana
Sokafy amin'ny navigateur ny `index.html`. Mila connexion internet ny motera Three.js CDN amin'ny voalohany.

## GitHub Pages
Ao amin'ny Settings > Pages, safidio ny Deploy from a branch, branch `main`, folder `/ (root)`, dia Save. Rehefa vita ny publication dia hiseho eo ny URL.

## Fanamarihana
Prototype de départ izy ity, fa tsy mbola version ultra-réaliste. Ny modely bus amin'izao dia procedural; mbola mila ampidirina ny modely 3D GLB/GLTF tena izy, textures, sons, map lavitra ary test amin'ny téléphones Android samihafa.
